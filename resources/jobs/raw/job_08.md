
# Software Engineer (AI/ML) - Computer Vision

**Company:** Blickfeld GmbH
**Location:** Munich, Germany

**Company Information:**

* **Industry:** Automotive Technology (develops LiDAR sensors and software for autonomous mobility).
* **Focus:** Provides high-performance LiDAR solutions for various applications.
* **Size:** Medium-sized company (around 100-200 employees).

**Job Description:**

Blickfeld is looking for a Software Engineer (AI/ML) with a focus on Computer Vision to join their team in Munich. You will be working on developing AI algorithms for processing LiDAR data.

**Responsibilities:**

* Develop and implement computer vision algorithms for object detection, tracking, and scene understanding using LiDAR data.
* Work with point cloud data and relevant machine learning techniques.
* Optimize algorithms for performance on embedded systems.

**Qualifications:**

* Bachelor's or Master's degree in Computer Science, Robotics, or a related field.
* Strong programming skills in Python and/or C++.
* Experience with computer vision and machine learning libraries (e.g., OpenCV, TensorFlow, PyTorch).
* Knowledge of point cloud processing is a plus.
